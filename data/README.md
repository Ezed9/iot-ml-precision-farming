# Data

Do not commit raw/private data here. Add a documented dataset card for every training dataset containing:

- Source URL or provider.
- License and permitted use.
- Collection date and geography.
- Feature definitions and units.
- Label definitions.
- Number of rows and class distribution.
- Missing-value and outlier handling.
- Known limitations and bias risks.

Use `data/raw/` and `data/processed/` locally; both are ignored by Git.
